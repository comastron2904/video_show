# 캐릭터 모델

Kenney "Mini Characters"(CC0, www.kenney.nl)의 일반인 캐릭터 13종입니다.
관객마다 닉네임에 따라 하나가 자동으로 배정되고, "다시 뽑기"를 누르면 다른 캐릭터가 나옵니다.

- `list.json` : 사용할 파일 목록과 크기 배율(scale)
- `Textures/colormap.png` : 모든 모델이 함께 쓰는 색상 텍스처 (지우면 안 됨)

캐릭터를 빼거나 더하려면 `list.json`의 files 목록을 고치면 됩니다.
(같은 팩의 character-worker.glb, character-robot.glb 등도 이 폴더에 넣고 목록에 추가하면 쓸 수 있습니다)
